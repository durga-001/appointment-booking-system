# MediSync: AI-Based Doctor Appointments Platform  
🔗 Live Demo: [medisync.com](https://medisync-1-4guz.onrender.com/)

MediSync is a full-stack platform built with React.js, Node.js, Express.js, and MongoDB. It features JWT-based RBAC for Admin/Doctor/Patient, AI-powered symptom checker, secure Razorpay bookings, and real-time appointment management with availability tracking and doctor workflows.
